# OLA Ride Analytics Dashboard

## Project Overview

**Objectives**

- Analyze overall ride bookings
- Track revenue and booking value
- Monitor cancellation patterns
- Evaluate vehicle-type performance
- Assess customer and driver ratings

  ---

**Tools Used**

- Power BI
- DAX
- Power Query
- Excel / CSV Dataset

  ---

**Dashboard Pages**

### 1. Overall Dashboard
- Total Bookings: 103K
- Total Booking Value: 35M
- Booking Status Distribution
- Ride Volume Trend Analysis

### 2. Vehicle Type Analysis
- Booking Value by Vehicle Type
- Success Booking Value
- Distance Travelled Analysis
- Vehicle Performance Comparison

### 3. Revenue Analysis
- Revenue by Payment Method
- Daily Ride Distance Distribution
- Top Customers by Booking Value

### 4. Cancellation Analysis
- Customer Cancellation Reasons
- Driver Cancellation Reasons
- Cancellation Rate Analysis

### 5. Ratings Analysis
- Customer Ratings by Vehicle Type
- Driver Ratings by Vehicle Type

**Key Insights**

- Success bookings account for approximately 62% of total rides.
- Cash is the most preferred payment method.
- Prime Sedan generates the highest booking value.
- Cancellation rate is around 28%.
- Customer and driver ratings remain close to 4.0 across vehicle categories.
